# E-มาลัย 🪷

เว็บแอปสำหรับ **ลากส่งพวงมาลัยจากนักศึกษาถึงอาจารย์แบบเรียลไทม์** เน้นใช้งานบนสมาร์ทโฟน

## วิธีเล่น

1. เปิดแอป เลือกบทบาท **นักศึกษา** / **อาจารย์** / **กรรมการ**
2. กรอกชื่อ–นามสกุล
3. **ฝั่งอาจารย์:** เห็น "หน้ารอรับ" (ดอกบัวใหญ่กลางจอ มีวงกลมหมุนรอบ) เป็นหลัก ป๊อปอัปเด้งเมื่อมีคนส่งมาจริง — พวงมาลัยที่ได้รับจะ **"แขวนสะสมบนราว"** ที่ค่อย ๆ เต็มและแกว่งเบา ๆ · ตอนพวงมาลัยลง มี **กลีบดอกไม้ระเบิด + เครื่องสั่น + เสียงกรุ๊งเฉพาะตัวของพวงมาลัยแต่ละแบบ** · มีลิงก์ "ดูประวัติที่ได้รับ" + **"🎴 การ์ดที่ระลึก"** · หน้าประวัติดูได้ทั้งหมด (ใหม่สุดอยู่บน) กดที่รายการเพื่อดูรูปใหญ่เกือบเต็มจอ มีปุ่ม **"⬇ บันทึกรูปพวงมาลัย"** ดาวน์โหลดเป็น PNG โปร่งใส ~900px · ถ้าอยู่หน้าประวัติแล้วมีมาลัยเข้า ป๊อปอัปมาลัยใหม่จะซ้อนทับขึ้นมา
4. **ฝั่งนักศึกษา:**
   - แถบเลือกพวงมาลัยแสดง **เฉพาะแบบที่แต่งเอง** — ครั้งแรกต้องกด **🎨 แต่งพวงมาลัย** สร้างก่อน (6 แบบพื้นฐาน + รูปนักศึกษา ใช้เป็นฐานเริ่มต้นในตัวแต่งเท่านั้น)
   - เลือกอาจารย์ปลายทาง (มีช่องค้นหาชื่อเมื่ออาจารย์เยอะ)
   - **ปัดการ์ดขึ้นด้านบน** → พวงมาลัยเหวี่ยงโค้งลอยออกจอไปเด้งขึ้นบนจอของอาจารย์ที่เลือก
   - **กดค้างที่การ์ดก่อนปัด = "ชาร์จพลัง"** (การ์ดเรืองแสง มีแถบพลังวิ่ง) ปล่อยแล้วปัดขึ้น → พวงมาลัยไปถึงอาจารย์แบบ **เต็มพลัง** (ใหญ่พิเศษ เรืองแสง กลีบเยอะ เสียงยาว)
5. **ฝั่งกรรมการ:** จำกัด 5 คน (หน้าแรกโชว์ X/5 ครบแล้วปุ่มเป็นสีเทากดไม่ได้) · เลือกพวงมาลัยแล้วปัดขึ้น (ชาร์จพลังได้เหมือนนักศึกษา) → ส่งให้อาจารย์ **ทุกคนที่ออนไลน์ ณ ตอนนั้น** พร้อมกัน · ส่งได้ **คนละ 1 ครั้ง** แล้วขึ้นปุ่มกลับหน้าแรก
6. **พวงมาลัยรวม (จอพิธี):** นักศึกษา/กรรมการกดปุ่ม **"🌼 เติมดอกไม้ในพวงมาลัยรวม"** เลือกดอก + สี → เติมได้ **หลายดอก** (เปิดชีตค้างไว้ เลือก–เติมซ้ำได้เรื่อย ๆ) ทุกดอกไปรวมกันเป็นพวงมาลัยยักษ์บนหน้า **`/wall`** (เปิดฉายในงานพิธี อัปเดตสด นับจำนวน โชว์ชื่อคนล่าสุด) · ปุ่มมุมล่างซ้ายของจอพิธี **"🙏 ส่งพวงมาลัยรวมให้อาจารย์ทุกคน"** = ตอนจบพิธีเด้งพวงมาลัยรวมขึ้นจอของอาจารย์ทุกคนพร้อมกัน

> หน้าแรกบรรทัด "ปีการศึกษา 2569" — กดย้ำ ๆ 5 ครั้งเพื่อแก้ไขข้อความปี (จำไว้ในเครื่องนั้น ไม่หายเมื่อกด "กลับหน้าแรก")
> ทุกหน้ามีปุ่ม **"กลับหน้าแรก"** — กดแล้วล้างชื่อ/พวงมาลัยที่แต่ง/คุกกี้ในเครื่อง เพื่อเริ่มใหม่ (ยกเว้นข้อความปีการศึกษา)
> อาจารย์เห็น **ประวัติย้อนหลัง** ว่าใครส่งมาบ้าง (กรรมการมี 🎖️ กำกับ) เข้าใหม่/รีสตาร์ทเซิร์ฟเวอร์ก็ยังอยู่
> พื้นหลังเป็นแอนิเมชันคลื่นน้ำ (หยุดอัตโนมัติถ้าตั้งค่า "ลดการเคลื่อนไหว")
> **พารัลแลกซ์เอียงเครื่อง:** ป๊อปอัปพวงมาลัยเข้าฝั่งอาจารย์จะขยับตามการเอียงเครื่อง (`deviceorientation` · iOS ขออนุญาตครั้งแรกตอนแตะหน้าจอ)
> เน้นสมาร์ทโฟน แต่บนแท็บเล็ต/iPad คอลัมน์กว้างขึ้น (620–700px) ตัวหนังสือ/ปุ่ม/canvas ตัวแต่งใหญ่ขึ้น (media query ≥700px, ≥1000px, + แนวนอนจอเตี้ย)

## รันบนเครื่อง

```bash
npm install
npm start
```

เปิด http://localhost:3000

## ใช้กับมือถือจริง (วง WiFi เดียวกัน)

1. รัน `npm start` บนคอมพิวเตอร์
2. หา IP ของเครื่อง: `ipconfig` (Windows) → ดู IPv4 Address เช่น `192.168.1.20`
3. บนมือถือทุกเครื่องเปิดเบราว์เซอร์ไปที่ `http://192.168.1.20:3000`
4. เครื่องหนึ่งเลือกอาจารย์ อีกเครื่องเลือกนักศึกษา แล้วลองส่ง

ถ้าจะใช้ข้ามอินเทอร์เน็ต ให้ deploy ขึ้นโฮสต์ที่รองรับ WebSocket (Render / Railway / Fly.io ฯลฯ) — โค้ดฟัง `process.env.PORT` อยู่แล้ว

ปรับได้ผ่าน env: `URL` (ทดสอบผ่าน tunnel จริงก็ได้), `TEACHERS`, `STUDENTS`, `ROUNDS`,
`SENDWIN` (กระจายการส่งกี่ ms), `PNG_RATIO`, `PNG_KB` (ขนาดรูปอัปโหลดจำลอง)

ดูสถานะเซิร์ฟเวอร์สด ๆ ได้ที่ `GET /stats` (จำนวน socket / หน่วยความจำ)

ผลทดสอบบนเครื่อง (Node 22, Windows):

| สถานการณ์ | คอนเนกชัน | การส่ง | ส่งถึง | ดีเลย์ ack (p95) | RAM เซิร์ฟเวอร์ |
|---|---|---|---|---|---|
| 50 อาจารย์ + 500 นศ. ส่งคนละ 1 | 550 | 500 | 100% | 1 ms | ~77 MB |
| 50 + 500 ส่งรัว 2,500 ครั้งใน 3 วิ (มีรูป 250KB) | 550 | 2,500 | 100% | 20 ms | ~71 MB |
| 100 + 2,000 ส่ง 6,000 ครั้ง (เกินเป้ามาก) | 2,100 | 6,000 | 100% | 78 ms | ~100 MB |

สรุป: เป้าหมาย 50 อาจารย์ + 500 นักศึกษา เหลือ headroom เยอะมาก Node process เดียวรับไหวสบาย

## ประวัติการส่ง (NoSQL / lowdb)

- เก็บด้วย **lowdb** (document store แบบฝังในตัว) ที่ไฟล์ `backend/data/history.json` — ไม่ต้องรันเซิร์ฟเวอร์ฐานข้อมูลแยก
- อาจารย์ล็อกอินด้วย **ชื่อ-นามสกุล** → เห็นเฉพาะรายการที่ส่งมาถึงชื่อนั้น (ทั้งหมด เรียงใหม่สุดก่อน)
- เซิร์ฟเวอร์เขียนไฟล์แบบรวมเป็นชุด (อย่างมากทุก 1.5 วิ) และ flush ตอนกด `Ctrl+C`
- เก็บล่าสุด `MAX_HISTORY` รายการ (ค่าเริ่มต้น 3000, ตั้งผ่าน env ได้) กันไฟล์บวม
- `committeeDone` = รายชื่อกรรมการที่ส่งไปแล้ว (กันส่งซ้ำ แม้รีเฟรช)
- รูปในประวัติเป็น **รูปย่อ ~96px**: พวงมาลัยมาตรฐานเก็บเป็น path, พวงมาลัยที่แต่งเองเก็บ thumbnail เล็ก ๆ (data URL)
- อยากล้างประวัติ: อาจารย์กดลิงก์ **"ล้างประวัติของฉัน"** ล่างสุดหน้าประวัติ (ลบเฉพาะรายการที่ตรงชื่อนั้นบนเซิร์ฟเวอร์) หรือปิดเซิร์ฟเวอร์แล้วลบไฟล์ `backend/data/history.json` ทั้งไฟล์
- ประวัติผูกกับ **ชื่อ-นามสกุลอาจารย์** ไม่ได้ผูกกับเบราว์เซอร์ — ล้างแคช/คุกกี้/กด "กลับหน้าแรก" ไม่ลบประวัติ พอล็อกอินชื่อเดิมก็เห็นเหมือนเดิม
- ชื่อซ้ำกันเป๊ะ = เห็นประวัติปนกัน (ปกติในงานจริงมักไม่ชน)

## แต่งพวงมาลัย (ฝั่งนักศึกษา)

ปุ่ม **🎨 แต่งพวงมาลัย** เปิดตัวแต่งบน `<canvas>` (พื้นหลังโปร่งใสเสมอ):

- **เทมเพลตกดเดียว**: 🤍 มะลิคลาสสิก / 👑 โทนทอง / 🌈 สายรุ้ง — แตะปุ่มเดียวใส่ทั้งชุด (ฐาน + ไล่สี + แสงเงา)
- **พวงมาลัยพื้นฐาน**: 6 แบบวาดเวกเตอร์ + รูปนักศึกษาชาย/หญิง (`assets/stu-*.svg` — PNG ลบพื้นหลังขาว → ฝังใน SVG) + **พวงมาลัยที่เคยเซฟไว้** (ต่อยอดงานเดิมได้)
- **✏️ โหมดวาด (freehand)**: วาดเส้นด้วยนิ้วบน canvas — เลือกสี/ขนาดเส้น, ลบเส้นล่าสุด/ล้างเส้น · เส้นถูกฝังเป็น `<path>` ในไฟล์ SVG ที่เซฟ
- **วางพวงมาลัย/รูป ทับเพิ่มเป็นเลเยอร์**: แตะพวงมาลัย/รูปใดก็ได้ → วางซ้อนบนงาน แล้วลาก–ย่อ/ขยาย–หมุน–กลับด้าน (2 นิ้วก็ได้) → 1 งานมีได้หลายพวงมาลัย
- **พวงมาลัยตั้งต้นก็ทำได้เหมือนสติกเกอร์** (แตะเพื่อเลือก) — ขยับ/ย่อขยาย/หมุน/กลับด้านได้ แต่ **ลบไม่ได้**
- แตะเพิ่ม **สติกเกอร์ emoji** — เลเยอร์ทุกชิ้น ลาก/ย่อขยาย (2 นิ้ว)/หมุน 360°/กลับด้าน/ลบได้
- **เปลี่ยนลำดับเลเยอร์**: เลือกเลเยอร์แล้วกดปุ่ม ⌃ (ขึ้นหน้า) / ⌄ (ลงหลัง) ทีละชั้น (พวงมาลัยตั้งต้นอยู่ล่างสุดเสมอ)
- **ทุกชิ้น (พวงมาลัยตั้งต้น + ทุกเลเยอร์) มีค่าปรับแต่งของตัวเอง** — เลือก object ไหน แผง "ปรับแต่งชิ้นที่เลือก" จะปรับอันนั้น:
  - **สี** (color) หรือ **ไล่สีได้ถึง 10 สี** (＋/× เพิ่ม–ลบ) + ทิศทางไล่สี + ปริมาณสีที่ทับ
  - **ความเข้ม** (saturate), **แสง** (brightness), **เงา** (drop-shadow), **ความกลมรี** (ยืดกว้าง/สูง)
  - "รีเซ็ตการปรับ" คืนเฉพาะชิ้นที่เลือก (ถ้าเป็นพวงมาลัยตั้งต้น คืนตำแหน่งกลับกึ่งกลางด้วย)
- export: SVG แยก node ต่อชิ้น (filter/mask/gradient คนละ id) — แต่ละชิ้นเก็บสีตัวเองครบ

กด **บันทึก** จะประกอบพวงมาลัยเป็น **SVG โปร่งใส** (เวกเตอร์ คมทุกขนาด ไฟล์ ~4KB) — ฝังพวงมาลัยพื้นฐาน + ไล่สี/แสงเงา (CSS filter + `mix-blend-mode:color` + mask) + สติกเกอร์ (`<text>`) ถ้าเบราว์เซอร์ประกอบ SVG ไม่ได้จะ fallback เป็น PNG 480×800 · เก็บใน `localStorage` ของเครื่องนั้น ลบได้ด้วยปุ่ม × · ไม่มีการอัปโหลดไฟล์จากเครื่อง

รูปพวงมาลัยพื้นฐาน (`public/assets/malai-*.svg`) ตั้ง `width/height` เป็น 4× ของ viewBox เพื่อให้แรสเตอร์ลง canvas/หน้าจอคมขึ้น

## กรรมการ

- จำกัด `MAX_COMMITTEE` คน (ค่าเริ่มต้น 5) — หน้าแรกโชว์ `X/5` อัปเดตสด ครบแล้วปุ่มเทากดไม่ได้
- ปัดขึ้น 1 ครั้ง = ส่งให้อาจารย์ทุกคนที่ออนไลน์ ณ ตอนนั้น (บันทึกประวัติให้ทุกคน)
- ส่งได้คนละ 1 ครั้ง (เช็คจาก `committeeDone` ตามชื่อ) แล้วขึ้นปุ่มกลับหน้าแรก
- slot ว่างเมื่อกรรมการออกจากระบบ · ถ้าไม่มีอาจารย์ออนไลน์เลยจะส่งไม่ได้ (ยังไม่นับว่าใช้สิทธิ์)

## พวงมาลัยรวม (จอพิธี `/wall`)

- นักศึกษา/กรรมการกดปุ่ม **"🌼 เติมดอกไม้ในพวงมาลัยรวม"** → เลือกดอก (10 แบบ) + เลื่อนสี → กด "เติมดอกไม้" · **เติมได้หลายดอก** (ชีตไม่ปิดเอง เลือก–เติมซ้ำได้) · เซิร์ฟเวอร์กันสแปมด้วย cooldown 250ms + เพดาน 80 ดอก/คน · เพดานรวม `MAX_WALL` = 800
- เปิด **`/wall`** บนจอโปรเจกเตอร์/ทีวี: ดอกไม้ทุกดอกเรียงเป็นพวงมาลัยรูปหยดน้ำล้อมตัวเลขตรงกลาง (1–4 วงซ้อนตามจำนวน) ขนาดดอกปรับอัตโนมัติ · โชว์ตัวนับ "N ดอก" + ป้ายชื่อคนล่าสุด · แกว่งเบา ๆ (เคารพ "ลดการเคลื่อนไหว")
- **ปุ่มมุมล่างซ้าย "🙏 ส่งพวงมาลัยรวมให้อาจารย์ทุกคน"** — เซิร์ฟเวอร์ประกอบดอกไม้ทั้งหมดเป็น SVG แล้วเด้งขึ้นจอของอาจารย์ทุกคนที่ออนไลน์ (เป็น `receive-garland` แบบเต็มพลัง + บันทึกประวัติ) · มี cooldown 8 วินาที · ยืนยันก่อนส่ง
- เก็บถาวรใน `backend/data/history.json` คีย์ `wall` — จอพิธีรีเฟรช/เปิดใหม่แล้วดอกไม้ยังอยู่ครบ

## เปลี่ยนรูปพวงมาลัย

รูปอยู่ที่ `public/assets/malai-1.svg` … `malai-6.svg` — แก้สี/รูปทรงแล้วรัน `node scripts/generate-garlands.js`

## การเชื่อมต่อ (Socket.IO)

| event | ทิศทาง | ข้อมูล |
|---|---|---|
| `register` | client → server | `{ role: 'student'\|'teacher'\|'committee', name }` |
| `committee-status` | server → clients | `{ count, max }` จำนวนกรรมการที่เข้าแล้ว (อัปเดตหน้าแรกสด ๆ) |
| `registered` | server → กรรมการ | `{ role, alreadySent }` ยืนยันเข้าห้องกรรมการสำเร็จ |
| `register-rejected` | server → กรรมการ | `{ reason }` กรรมการเต็ม 5/5 |
| `teachers` | server → clients | `[{ id, name }]` รายชื่ออาจารย์ออนไลน์ |
| `history` | server → อาจารย์ | `[{ id, studentName, fromRole, thumb, at }]` ประวัติทั้งหมด (ใหม่สุดก่อน) ส่งตอน register |
| `send-garland` | นักศึกษา → server | `{ toTeacherId, src, thumb, power }` (`power` 0–1 = ระดับชาร์จ) |
| `send-to-all-teachers` | กรรมการ → server | `{ src, thumb, power }` ส่งให้อาจารย์ทุกคนออนไลน์ (ครั้งเดียว) |
| `receive-garland` | server → อาจารย์ | `{ src, fromName, fromRole, power, at }` (`fromRole` = `student` / `committee` / `wall` · `power > 0.5` = เต็มพลัง) |
| `send-ok` / `send-all-ok` / `send-failed` | server → ผู้ส่ง | ผลการส่ง (`send-all-ok` มี `{ count }` = จำนวนอาจารย์ที่ส่งถึง) |
| `clear-my-history` | อาจารย์ → server | ลบประวัติทุกรายการที่ `teacherName` ตรงชื่อตัวเอง |
| `history-cleared` | server → อาจารย์ | `{ removed }` จำนวนรายการที่ลบ (ตามด้วย `history` เป็น `[]`) |
| `wall-hello` | จอ `/wall` → server | ขอสถานะพวงมาลัยรวมทั้งหมด |
| `wall-state` | server → จอ `/wall` | `[{ id, e, hue, name, at }]` ดอกไม้ทั้งหมดปัจจุบัน |
| `wall-add` | นักศึกษา/กรรมการ → server | `{ e, hue }` เติมดอกไม้ (หลายดอกได้ · cooldown 250ms · เพดาน 80/คน) |
| `wall-flower` | server → ทุก client | `{ id, e, hue, name, at }` ดอกไม้ใหม่ที่เพิ่งเติม (จอ `/wall` จัดเรียงเป็นพวงมาลัยใหม่ทั้งหมดแบบเรียลไทม์) |
| `wall-added` | server → ผู้เติม | `{ count, mine, limit? }` ยืนยัน (`mine` = คุณเติมไปกี่ดอกแล้ว) |
| `wall-send-all` | จอ `/wall` → server | สั่งประกอบพวงมาลัยรวมเป็น SVG → บันทึกไฟล์ `backend/data/wall-*.svg` → เด้งให้อาจารย์ทุกคนออนไลน์ (เป็น `receive-garland` เต็มพลัง `fromRole:'wall'`) · cooldown 8 วิ |
| `wall-send-all-ok` / `wall-send-all-failed` | server → จอ `/wall` | `{ count }` จำนวนอาจารย์ที่ส่งถึง / `{ reason }` |

## ดาวน์โหลดรูป (HTTP, ไม่ใช่ socket)

| route | ใช้ทำอะไร |
|---|---|
| `POST /prepare-download` | รับ `{ png(dataURL), name }` → เก็บชั่วคราวในหน่วยความจำ (TTL 90 วิ) → คืน `{ token }` |
| `GET /dl/:token` | ส่งไฟล์ PNG พร้อม `Content-Disposition: attachment; filename*=UTF-8''<ชื่อ>` (ชื่อไทยถูกต้องแม้บน iOS/Safari) · token ใช้ครั้งเดียว |

ปุ่ม "บันทึกรูปพวงมาลัย" ในหน้าดูรูปใหญ่ จะเรนเดอร์เป็น PNG ~900px แล้วลองผ่าน `/prepare-download` ก่อน (ได้ไฟล์ชื่อ `e-malai-<ชื่อผู้ส่ง>.png`) ถ้าเซิร์ฟเวอร์ไม่รองรับจะ fallback เป็นดาวน์โหลดฝั่ง client
